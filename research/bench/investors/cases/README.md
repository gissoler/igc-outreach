# Casos del benchmark de investors

Este directorio está vacío intencionalmente: v0 no contiene perfiles ni casos reales.

La corrida formal debe añadir `profiles/inv-prof-<id>.json`, `inv-case-<id>.json` y `manifest.json` solo después de seguir `docs/benchmark/investors/PROTOCOL.md`. Debe haber 12–25 casos ancla, 2–3 nulos, máximo dos anclas por perfil y diversidad explícita de sector, etapa, región y modelo de negocio.

Los únicos casos actuales son ficticios y viven en `research/tests/agent/fixtures/investor-world-v0/`; nunca deben mezclarse con el gold set.
